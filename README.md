# ВЧ КИМ — справочник по ролям

Интерактивное ЧАВО по формированию вариативной части контрольных измерительных материалов.

[Открыть справочник](https://olgakraven.github.io/vch-kim-faq/)

- Маршруты разработчика, куратора образовательной организации и работодателя.
- Поиск по вопросам и пояснения к каждому шагу.
- Числовые значения, форматы файлов, термины и исходный чек-лист.
- Ссылки на источники и пояснения к неоднозначным требованиям.

Справочник подготовлен по предоставленным руководствам от 20.10.2026, чек-листу и уточнениям порядка работы. Источники указаны в самой странице.

## Использование и обновление

Откройте `index.html` в браузере или воспользуйтесь опубликованной ссылкой. Страница работает без сборки и внешних зависимостей; интернет нужен для перехода к внешним материалам.

GitHub Pages публикует корень ветки `main`. Для обновления замените `index.html` проверенной версией и отправьте изменения в `main`.

Шрифт Raleway встроен в HTML; его лицензия SIL Open Font License сохранена в исходном файле.
